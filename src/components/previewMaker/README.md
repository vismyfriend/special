# previewMaker

Перенеси папку целиком в `src/components/previewMaker/`. Относительный импорт рассчитан на существующий файл `src/composables/whatGameDataToUse.js`.

Для первого теста открой `src/pages/ChooseGame.vue` и импортируй компонент внутри существующего `<script setup>`:

```js
import PreviewMaker from 'src/components/previewMaker/PreviewMaker.vue'
```

Помести рядом с текущим блоком карточек:

```vue
<PreviewMaker title="Игры по этому набору" />
```

Компонент сам читает `route.params.missionName` и вызывает `loadWords(missionName)` один раз на набор. Ссылки строятся через существующий Vue Router. Поддерживаются уже зарегистрированные `dialSafe`, `find-pairs-easy` и `wordSearch`. Новые маршруты для этого подключения не нужны. Если вставляешь компонент на страницу без `missionName` в маршруте, передай `:mission-name="ключНабора"`.

Если нужен тот же список разрешённых игр, что в текущем меню, передай их пути:

```vue
<PreviewMaker :available-games="filteredGames.filter(game => game.active).map(game => game.path)" />
```

Пересечение рассчитывается с тремя поддерживаемыми механиками. В просмотренном `ChooseGame.vue` в списке есть `find-pairs-easy`, а `dialSafe` и `wordSearch` зарегистрированы в роутере отдельно. При передаче фильтра они появятся, когда будут добавлены и в список доступных игр.

## Откуда берутся данные

- **Файл в Git.** После обычной сборки и публикации `loadWords` увидит обновлённый набор в `shortWordsData`. Мини-превью строятся автоматически.
- **Google Sheets.** Используется существующая поддержка ключей `gsheet:…` и кеш загрузчика.
- **Свой API.** Просмотренный `whatGameDataToUse` поддерживает файлы и Google Sheets. Когда появится источник с твоего бэкенда, подключи его к общему `loadWords`. Тогда и каталог, и сами игры смогут открыть новый набор без пересборки. Назначь набору стабильный ключ, который понимают игровые маршруты, и используй его как `missionName`.

Если страница уже получила массив от бэкенда, можно сразу передать его в `<PreviewMaker :words="rows" :mission-name="setKey" />`. Если загрузку нужно делегировать компоненту, используй `:load-set="fetchWords"`. Функция должна принимать `(missionName, { signal })` и возвращать массив. Эти способы подменяют источник только для каталога. Сами игры должны уметь загружать тот же набор по ключу.

Формат записи — `{ eng, ru, hint, taskPicture }`. Поддерживается `rus` вместо `ru`. Для двух игр с переводами нужен текстовый перевод. Word Search показывает отдельные английские слова от 3 до 13 букв и может использовать подсказку с картинкой, эмодзи или текстом. Когда данных для механики не хватает, её карточка пропускается.

Карточки показывают небольшой стабильный фрагмент данных. Игровые компоненты загружаются только при переходе по ссылке. Перетаскивание передаёт URL. Это компонент каталога внутри приложения. Для публичного поиска по темам адрес без `#` и подготовка HTML остаются отдельным этапом.
